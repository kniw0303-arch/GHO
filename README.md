# 실시간 자막 번역 (LiveSubKo)

화면의 영어 자막을 접근성 서비스로 읽어 와서 한국어 자막으로 영상 위에 띄웁니다.

## 동작 방식
- **자막 읽기**: Android '실시간 자막(Live Caption)' 창 + 영상 앱의 subtitle/caption 뷰
- **하이브리드 번역**: ML Kit(기기 안에서, 수십 ms)으로 바로 띄운 뒤 → Claude/Gemini 번역이 도착하면 자연스러운 문장으로 바꿈
- **동시 번역에 가깝게**: 말하는 도중의 부분 문장도 바로 번역하고, 말이 0.45초쯤 멈추면 LLM에 미리 요청해 둠. 문장이 끝날 때 결과가 캐시에 있으면 바로 교체
- **문맥 유지**: 앞 대사 4줄을 LLM에 같이 보내서 반말/존댓말이나 말투가 일관되게 유지됨

## 빌드
### 방법 A — Android Studio
1. 폴더 열기 → Gradle 동기화 → ▶ Run (또는 Build → Build APK)

### 방법 B — GitHub (PC에 개발 도구가 없을 때)
1. GitHub에 새 저장소를 만들고 이 폴더 내용을 그대로 올림
2. Actions 탭 → "Build APK" 실행이 끝나면 Artifacts에서 `LiveSubKo-apk` 다운로드
3. 폰에서 APK 설치

## 처음 설정
1. 앱 실행 → **ML Kit 모델 다운로드**
2. Claude 또는 Gemini **API 키** 입력 → '번역해 보기'로 확인
3. **① 접근성 설정** → 실시간 자막 번역 켜기
   - 막히면: 설정 → 애플리케이션 → 실시간 자막 번역 → ⋮ → **제한된 설정 허용**
4. **② 실시간 자막** 켜기 (볼륨 버튼 → 자막 아이콘)
5. 영상을 틀면 한국어 자막이 나옴. 자막을 끌어서 위치를 옮길 수 있고, 탭하면 잠깐 숨겨짐

## 팁
- '작품 정보'에 장르나 인물 관계를 적어 두면 말투가 더 자연스러워짐
- 기본 모델: `claude-haiku-4-5`, `gemini-2.5-flash-lite` (속도 우선). 설정에서 바꿀 수 있음
- 실시간 자막 원본 창이 거슬리면 Live Caption 설정에서 창을 작게 하거나 화면 위쪽으로 옮겨 두세요
